# Chatter 1.0.2 — Public preview

Chatter brings your Glyph Matrix to life as you type, revealing selected phrases rather than the text you type.

## Changes

- Updated the preview portrait with warm skin tones, forest-green clothing and geometric paper-cut shading.
- Corrected eye and face-shadow layering, moved the thumb to the screen-facing side and simplified the ear.
- Disabled device-motion rotation of the portrait; breathing animation and the live Glyph preview remain available.
- Replaced the Slang collection with 30 mild to moderate English swears. The category remains named Slang; its description now identifies the content.
- Resets phrase progression when updating the catalog.

## Download and installation

Download **Chatter-1.0.2.apk**. **SHA256SUMS.txt** provides its SHA-256 checksum.

For Nothing Phone (3) and Phone (4a) Pro with Android 14+ and compatible Nothing OS firmware. Enable the accessibility service for typing effects and disable competing Glyph typing effects.

This APK uses the same dedicated release signing key as 1.0.1, allowing an in-place upgrade from that public release. Debug builds use a different certificate and may require manual removal first; uninstalling removes local app data.

This public repository contains downloads, documentation and license notices only. Application source code remains private.

# Chatter 1.0.1 — Public preview

## What if your Glyph started talking nonsense?

As you type, Chatter brings your Glyph Matrix to life—one character at a time.

Choose from everyday catchphrases, casual slang, or food names from around the world. Have something of your own to say? **Pinned text** keeps your message on the Glyph Matrix for one hour.

Chatter displays your selected phrases—not what you’re actually typing.

**You do the typing. Let your Glyph Matrix do the chatter.**

### Included in this build

- Live Matrix previews and a typing playground.
- Chinese pinned text using native Fusion Pixel Font glyphs.
- One-pixel-column pinned-text scrolling with the previous overall travel speed preserved.
- A fix for the Chinese font packaging error that caused repeated crashes when restoring a Chinese pin.

### Before installing

- Compatible Nothing Glyph Matrix hardware and Android 14+ are required.
- Enable Chatter’s accessibility service for typing effects.
- Disable competing system/app Glyph typing effects.
- Chinese Pin is supported on 13×13 and 25×25 matrices.
- Source code is not included. GitHub’s source archives contain documentation only.

Download **Chatter-1.0.1.apk** below. **SHA256SUMS.txt** contains the download checksum.

This build switches to the official public Glyph Matrix SDK 2.0 and uses a dedicated release signing key. It is not debuggable. Private/debug builds may need to be manually uninstalled first because their signing certificate differs; save your pin before uninstalling, which removes app data. The application source repository remains private.

Compatible SDK targets: Phone (3) and Phone (4a) Pro. Other device profiles are not supported by this public build.
